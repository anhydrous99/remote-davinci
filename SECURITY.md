# Security policy

## Supported versions

Security fixes are applied to the `main` branch. This project does not yet
publish versioned releases.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/anhydrous99/remote-davinci/security/advisories/new).
If that form is unavailable, email `anhydrous99@gmail.com` with the subject
`remote-davinci security report`. Do not open a public issue. Include the
affected commit, impact, reproduction steps, and any suggested remediation. Do
not include live credentials, enrollment material, private keys, or production
data.

You should receive an acknowledgment within seven days. Please allow time for a
fix to be developed and published before public disclosure.
